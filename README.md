# 涼丸産業 AIパチンコメーカー

架空メーカー「涼丸産業」が、どのIPとコラボして台を出すかをAIが分析するシミュレーションツール。単一HTML＋JSONで動作し、GitHub Pagesでの公開を想定（相対パスのみ、外部ライブラリ非依存。レーダーチャートもインラインSVGで自前描画）。

## 構成

```
index.html               画面本体（HTML+CSS+JS 単一ファイル）
data/ip_candidates.json  コラボ候補データ
README.md                本ファイル
```

`data/ip_candidates.json` の各要素は以下の項目を持つ（項目名は厳守）。

| フィールド | 内容 |
|---|---|
| id | 一意なID |
| name | IP名 |
| category | カテゴリ（アニメ/漫画/ゲーム等、フィルタに使用） |
| pachinko_history | 過去のパチンコ化実績 |
| awareness | 認知度（0-100） |
| core_fit | パチンコ世界観との相性（0-100） |
| youth_fit | 若年層親和性（0-100） |
| license_cost | ライセンス費用感（"低" / "中" / "高"） |
| freshness | IPの鮮度（0-100） |
| risk | リスク（文章） |
| why | 推す理由（文章） |
| sources | 出典URLの配列 |

## 画面構成（2026-09-02 初見向けUX改修後）

1. **AI分析パネル（ページ最上部・ヘッダー直下）** - 読み込み時にIPを1件ランダムに自動選択し、開いた瞬間に架空機種名・総合スコア・レーダーチャート・シナリオ試算・シェアボタンが見える構成。以降は「🎲 別のIPで診断」ボタンで再抽選できる。
2. **主役ボタン2つ**（高さ48px以上・親指タップ想定）
   - 「🎲 別のIPで診断」: ランダムに別のIPへ切替
   - 「あなたの推しは？」: カード一覧までスムーズスクロール
3. **結果をXでシェア** - 分析パネル内のボタンから `https://x.com/intent/post?text=...` を新規タブで開く（URLエンコード済み）。文面はIP名・機種名・総合スコアを含む定型文。
4. **絞り込み（カテゴリフィルタ）** - `<details>` で既定閉じ。開くとカテゴリチップが表示される。
5. **コラボ候補一覧** - カード形式。説明文は1行省略表示（CSS `-webkit-line-clamp`）。カードをタップすると分析パネルへ反映しスクロール。
6. **ランキングタブ** - 総合スコア順の一覧表（カテゴリフィルタ可）。
7. **メーカー経営モード** - 冒頭に「年間4機種を選んでメーカーの1年を組んでみよう」の説明文を追加。4機種の年間ラインナップ枠を編成し、年間売上・ライセンス費合計・カテゴリ偏りの警告を表示。
8. **計算の考え方** - `<details>` で既定閉じ。用語は平易な表現に統一（下記参照）。

### 用語の平易化（2026-09-02）

画面表示・計算説明・レーダーチャート軸ラベルすべてで統一。

| 内部項目 | 旧表記 | 新表記 |
|---|---|---|
| core_fit | コア客層適合 / 世界観との相性 | 今のお客さんウケ |
| youth_fit | 若年訴求 / 若年層親和性 | 若い人ウケ |
| freshness | 旬度 / 鮮度 | 今の話題性 |
| license_cost補正 | ライセンス費補正 | 版権のとりやすさ |

## 計算式（乱数不使用・すべて決定論的）

- **総合スコア** = `awareness×0.3 + core_fit×0.3 + youth_fit×0.15 + freshness×0.15 + ライセンス費補正`
  - ライセンス費補正: 低=+10 / 中=0 / 高=-10
  - 0〜100にクランプ
- **シナリオ試算**（強気/標準/弱気、係数はそれぞれ 1.3 / 1.0 / 0.7）
  - 導入台数(推定) = `3,000台 × (総合スコア/100) × シナリオ係数`
  - 導入店舗率 = `min(100%, 総合スコア × シナリオ係数 × 0.9%)`
  - 稼働寿命(週) = `(8 + 総合スコア/100×20) × 寿命係数`（強気1.2 / 標準1.0 / 弱気0.8）
  - メーカー売上 = `導入台数 × 台単価(仮定40万円)`
- **経営モードのライセンス費合計**は `license_cost` を仮定金額（低3,000万/中8,000万/高2億円）に換算して合計。
- **架空機種名**はIP名と定型パターン（P〈IP名〉〜AI覚醒〜 等）を組み合わせて生成する決定論的な文字列で、実在機種名ではない。

すべての計算式は画面下部「計算の考え方」パネルにも日本語で明記している。

## 禁止事項（実装時に遵守）

- 設定・出玉・還元率・勝てる等を匂わせる文言は使用していない。
- 実在メーカー名を自社として名乗っていない。
- 外部送信・アナリティクスは実装していない（fetchはローカルの`data/ip_candidates.json`のみ）。
